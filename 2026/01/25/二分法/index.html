二分法的边界问题

题目

给定一个按照升序排列的长度为 n 的整数数组，以及 q 个查询。

对于每个查询，返回一个元素 k 的起始位置和终止位置（位置从 0 开始计数）。

如果数组中不存在该元素，则返回 -1 -1。

输入格式

第一行包含整数 n 和 q，表示数组长度和询问个数。

第二行包含 n 个整数（均在 1∼10000 范围内），表示完整数组。

接下来 q 行，每行包含一个整数 k，表示一个询问元素。

输出格式

共 q 行，每行包含两个整数，表示所求元素的起始位置和终止位置。

如果数组中不存在该元素，则返回 -1 -1。

数据范围

1≤n≤100000
1≤q≤10000
1≤k≤10000

输出样例：

解答

特性 找左边界 (BL) 找右边界 (BR)
目标 寻找 $\ge k$ 的第一个数 寻找 $\le k$ 的最后一个数
区间划分意图 把区间分为 [<k] 和 [>=k] 把区间分为 [<=k] 和 [>k]
Check 条件 if (q[mid] < k) if (q[mid] <= k)
条件成立时 数太小了，抛弃左边 l = mid + 1 数可能是答案，保留左边 l = mid
条件不成立时 数可能是答案，保留右边 r = mid 数太大了，抛弃右边 r = mid - 1
死循环风险 r = mid 不会死循环 l = mid 会死循环
Mid 计算 mid = l + r >> 1 mid = l + r + 1 >> 1
